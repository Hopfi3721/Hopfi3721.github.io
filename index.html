pingwatch — мониторинг доступности

Go · SQLite · Docker

Сервис проверяет HTTP-эндпоинты по индивидуальному расписанию и присылает алерт в Telegram один раз на переход «работает → упал». Встроенный дашборд, история латентности, p95, uptime.

  • пул воркеров и машина состояний для алертов без спама
  • 59 тестов, включая go test -race
  • один бинарник и один файл SQLite — без Postgres и Redis

Парсер каталога в CSV

Go · CLI

Консольная утилита обходит страницы листинга в несколько горутин, соблюдает интервал между запросами, повторяет запросы на 429 и 5xx и выгружает результат в CSV, который открывается в Excel без «кракозябр».

  • селекторы задаются флагами — новый сайт без правки кода
  • учёт Retry-After, отмена по Ctrl+C с сохранением собранного
  • CSV: UTF-8 с BOM, разделитель ;

tg-orders-bot — приём заявок

Python · aiogram 3 · SQLite

Бот проводит клиента по форме из пяти шагов, сохраняет заявку, уведомляет администратора и даёт ему кнопки «В работу», «Готово», «Отклонить». При смене статуса клиент получает сообщение, все заявки выгружаются в CSV.

  • валидация имени, телефона и описания, отправка контакта кнопкой
  • антифлуд и защита от повторных заявок
  • 20 тестов на слой хранения, выгрузку и валидацию
